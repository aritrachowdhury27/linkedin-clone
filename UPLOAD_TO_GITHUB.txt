3. Click the "+" icon (top right) → "New repository"
4. Fill in:
   - Repository name: pronetwork-linkedin-clone
   - Description: Professional networking platform inspired by LinkedIn

   - ⚠️ IMPORTANT: DO NOT check any initialization options
     (no README, no .gitignore, no license - we already have these!)
5. Click "Create repository"

================================================================================
STEP 4: PUSH YOUR CODE TO GITHUB
================================================================================

GitHub will show you commands. Use these (replace YOUR_USERNAME):

git remote add origin https://github.com/YOUR_USERNAME/pronetwork-linkedin-clone.git
git branch -M main
git push -u origin main

Wait a few seconds for the upload to complete.

================================================================================
STEP 5: VERIFY UPLOAD
================================================================================

1. Refresh your GitHub repository page
2. You should see all your files
3. README.md should display nicely
4. Check that node_modules and dist folders are NOT uploaded (.gitignore works!)

STEP 7: ENABLE GITHUB PAGES (Optional - for live demo)
================================================================================

To deploy your app online:

1. Go to repository Settings → Pages
2. Source should automatically be "GitHub Actions"
3. Wait for the workflow to complete (check Actions tab)
4. Your site will be live at:

⚠️ For GitHub Pages to work, you may need to update vite.config.ts:
   Add: base: '/pronetwork-linkedin-clone/'
   Then commit and push the change.
